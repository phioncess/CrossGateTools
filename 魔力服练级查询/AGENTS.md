# 项目界面规则

## 字号与可读性

- 不得为了压缩布局使用过小文字。主要标签、地点名称和按钮主文案不得小于 `18px`；辅助说明、等级范围和按钮次文案不得小于 `16px`。
- “魔力装备档案”现有的 `18px / 16px` 大小文字层级是本项目的可读性基准；新增或修改紧凑型控件时优先沿用该层级。
- 桌面端与移动端都必须保持上述字号下限。响应式样式只能调整排列、宽度、间距和滚动方式，不得缩小文字规避空间不足。
- 快速索引等可点击区域应随字号同步扩大，并保留足够的内边距和最小高度；内容过多时使用横向滚动，不挤压文字。

## 检查方式

- 默认只做静态检查，包括选择器覆盖关系、断点规则、语法和关键尺寸核对。
- 除非用户明确要求演示或视觉验收，否则不要自动打开浏览器、启动界面预览或展示页面。
