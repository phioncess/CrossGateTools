## 3. 主要源文件

| 文件 | 用途 |
| --- | --- |
| `work\index-template.html` | 页面模板、CSS、计算和交互，是主要修改入口 |
| `work\molibaike-items.json` | 1,139 件装备数据 |
| `work\molibaike-professions.json` | 45 个职业及六个阶段装备上限 |
| `work\molibaike-cache\detail-*.html` | 原始物品详情缓存，用于特殊说明 |
| `work\profession-cache` | 职业页缓存 |
| `work\molibaike-parser.js` | 装备、区间、职业和单双手解析 |
| `work\build-equipment-html.js` | 注入数据、提取详情、生成并导出成品 |
| `work\scrape-molibaike.js` | 装备抓取脚本 |
| `work\scrape-professions.js` | 职业抓取脚本 |
| `work\sync-weapon-hands.js` | 同步武器单双手信息 |
| `work\test-*.js` | 数据、计算、宝石、布局和单双手测试 |
| `work\verify-html.js` | 内联脚本语法及关键页面结构检查 |
