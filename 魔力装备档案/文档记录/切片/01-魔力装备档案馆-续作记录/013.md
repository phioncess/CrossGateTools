## 12. 构建与测试

在项目目录执行：

```powershell
node work/build-equipment-html.js
$tests = Get-ChildItem -LiteralPath 'work' -Filter 'test-*.js' | Sort-Object Name
foreach ($test in $tests) {
  node $test.FullName
  if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
}
node work/verify-html.js
```

测试职责：

- `test-database-completeness.js`：数量、分类、ID 唯一性、职业完整性，以及每件物品必须具有合法的结构化服别。
- `test-equipment-calculator.js`：基础过滤、合计、宝石和合法性。
- `test-equipment-v2.js`：区间、类型、饰品推荐、结构化服务器过滤和等级限制。
- `test-layout-2k.js`：旧版页面宽度和宝石布局声明。
- `test-molibaike-parser.js`：列表、详情、区间和职业解析。
- `test-special-gems.js`：特殊宝石、已移除宝石不会回归、特殊说明、典型怀旧／道具服饰品分类和 14 列宝石网格。
- `test-weapon-hands.js`：单双手和副手规则。
- `verify-html.js`：脚本编译、响应式声明和 7 个装备栏。

### 测试缺口

`test-layout-2k.js` 仍检查较早的 2,160px、390px、12 列和 1,900px 断点。末尾 CSS 已覆盖为 2,400px、440px、14 列和新断点，所以该测试通过也不能证明最终布局正确。后续应改为验证最终层叠结果，至少覆盖：

- 普通文字最终不小于 16px，重要数值为 20px。
- 结果栏最终为 440px。
- 宝石最终为 14 列单排且没有横向滚动。
- 窄屏单列装备卡片仍可读。
- 成品中不存在“命中来源：”“hitSources”或“hit-explanation”。
