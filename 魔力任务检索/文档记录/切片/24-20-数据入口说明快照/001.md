# 任务结构数据

正式数据入口是 `database.json` 与 `quests/*.json`。

- `database.json`：数据库版本、记录格式和任务数量清单。
- `quests/<任务ID>.json`：一条任务一个文件，是构建、验证和页面发布的唯一事实输入。
- 拆分前的单体快照与历史核验台账已移入 `_legacy-quarantine/2026-09-27/data-src/`，不参与构建或验证。

旧批次工具已移入隔离目录。新增或修正任务时，只修改对应的分任务 JSON，并执行 `npm run audit:contract`、`npm run build:missions`、`npm run build`、`npm run verify:data`、`npm run verify` 和 `npm run verify:dom`。
