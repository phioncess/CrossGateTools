## 十五、空战斗卡与内部键泄漏修复（2026-09-25）

- 页面曾把只有战斗触发点、没有敌人数值的结构化记录渲染成空卡，并以 `base-guard`、`mindless-chief` 等内部 ID 作为标题；《被夺走的贡品》截图暴露了该问题。
- 全库共发现 34 个任务、57 条此类记录。现在不再生成空战斗卡，战斗触发点仍保留在任务流程；若整项任务都没有可核验敌人参数，BOSS 区统一显示“原攻略未单列 BOSS 数据”。
- 同一任务同时具有完整战斗和无参数战斗时，只渲染有敌人资料的战斗，并以一条统一说明标记其余触发点，不显示内部 ID 或推测数值。
- 补齐 `randomOneOf` 分支渲染：《最后的洗礼》和《斗技场争雄》的随机 BOSS 组合现在按各自分支展开，不再退化为空卡。
- DOM 全库检查改为只统计可渲染战斗，并强制每张战斗卡至少包含一张敌人卡；任何连字符形式的内部战斗键泄漏都会直接失败。资源版本提升至 `20260925-12`。
