# 魔力宝贝怀旧服任务检索

纯静态离线工具，双击 `index.html` 即可使用，无需服务端。

## 首版功能

- 组合下拉框：既可下拉选择，也可直接输入任务名、俗称、系列名或拼音首字母。
- 聚焦输入框会临时清空当前任务名；若没有输入新内容，离开输入状态时会自动恢复原值。
- 模糊检索：支持包含、前缀和按顺序漏字匹配。
- 关系跳转：系列任务展示完整关系链、上一项和下一项；任务卡同时展示直接前置和后续索引。
- 任务正文：展示关键坐标、接取条件、逐步流程和注意事项，并保留原攻略链接供完整核验。
- 战斗资料：关键首领战记录等级、血量、数量、技能/特性和打法建议；无首领战会明确标注。
- 奖励资料：区分必得奖励、概率掉落和关联道具，记录已核验的饰品/装备属性及后续用途。
- URL 定位：选择任务后写入 `#quest=任务ID`，刷新后仍可回到原任务。
- 本地离线：已核验详情在 `data.js`，完整目录与关系索引在 `catalog.js`；外链只用于打开原始攻略。

## 资料范围

采用“任务级保留、参数级裁剪”：未标服务器的旧任务视为通用任务并保留；明确含怀旧服版本的任务也保留。若同一任务同时存在道具服、时长服等多个版本，只采用怀旧服路线和参数；仅明确属于其他服务器且不含怀旧服版本的条目不进入工具。

任务目录已从任务系列导航恢复，含通用旧任务及怀旧服任务；目录中的每个任务均读取对应详情页，提取实际流程、坐标、条件、战斗数据和奖励。所有任务均归入系列或任务组，页面严格依据详情页中的任务名称和道具来源生成直接前置与直接后续，不用编号相邻冒充前置。

生成过程会删除详情中的道具服、时长服参数段，并对前置关系执行重复、断链、自引用和循环检查。若原攻略没有列出某个独立字段，页面不会用占位数据或推测内容冒充完整资料。

后续补数据时，在 `data.js` 的 `QUESTS` 中追加对象即可。`prerequisites` 填其他任务的 `id`；同一系列填写相同 `series` 与递增 `order`。
