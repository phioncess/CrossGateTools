## 当前功能

- 仅展示怀旧服实际职业，并排除暗黑骑士（怀旧服为骑士称号）、教团骑士、舞者。
- 职业介绍与星级评价。
- 就职、见习、一转、二转、三转路线；四转、五转不进入成品数据与界面。
- 按当前阶段显示可学习技能及最高等级；点击技能查看地点、教导人、费用、说明与备注。
- 按当前阶段显示可装备类型和最高等级；等级为 0 的类型自动隐藏。
- 职业名、分类和技能搜索，支持离线打开。
- 右侧资料采用单列阅读顺序，不再使用会覆盖内容的粘滞双栏。
- 原始职业正文会拆分为职业定位、得意技能、技能声望与备注，星级评价不在正文重复显示。
- 职业头图和阶段切换栏在桌面端随右侧内容滚动冻结，移动端恢复普通流式布局。
- 成长路线只显示当前阶段：见习显示就职要求，一转至三转分别只显示对应晋阶要求。
- 技能改为“分类 → 具体技能”两级选择，详情固定显示在技能区内，不再铺开全部技能卡或打开弹窗。
- 正文以 15～16px 为主，辅助文字不低于 12px，并针对窄屏重新排版。
